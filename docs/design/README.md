# Design

`vibrant_celebration_reference.md` é um design system de referência (saiu de
uma ferramenta tipo Google Stitch) que **não é mais a fonte de verdade**.

Os tokens reais usados no `design_system/` deste app foram extraídos ao vivo
do CSS do site em produção (`https://happ-marketplace.comcode.com.br/`):
cor primária `#FF3F81`, secundária `#3F8CFF`, destaque `#2DF3A1`, fonte
`Quicksand`, raios pequenos (tema PrimeNG "Aura"-like). Ver
`lib/design_system/tokens/` e a seção 3 do `AGENTS.md`.
